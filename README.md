# Block Tales (Roblox)

## Notes
- This game is not yet finished, as it's still receiving new updates. Everything is subject to being balanced, changed, and more as the game is developed!

## Goal(s)
- Beat the Game (all Chapters up to the latest version)
- Beat a Specific Chapter (selectable via YAML option)

## Items
- Cards (Useful/Progression)
- Important Things (Progression)
- Consumables (Filler/Useful)
- TIX (Filler)
- BUX (Progression for Shopsanity)

## Checks
- Collecting Important Things
- Collecting Items on Maps
- Collecting Cards
- Collecting BUX
- Beating Bosses
- Defeating Unique Enemies

## Options
- Remove Post-Goal Checks: A setting that allows the Player to remove any Checks in Chapters that are found after their Goal.
- Solo Mode: Remove Items that are only useful in multiplayer.
- I Spy Logic: Add logic to some of the game's semi-hidden BUX Checks.
- Soul Type: Are you a pure soul or a dark soul? Affects some Checks and what the player is/isn't allowed to do.
- Optional Bosses: Add Items and Checks related to the optional Bosses in the game.
- Shopsanity: Each item in Shops is a Check.
  - Includes an extra toggle for the BUX Shop specifically, which is disabled if Shopsanity is disabled.
    - *Also* has a toggle for starting the Multiworld with all of the BUX Shop Checks hinted.
- Levelsanity: Each Level Up is a Check. (The level cap for each Chapter would be logically accounted for.)
- Fishsanity: Each of the fish that can be caught in the Meadows Fishing Spot is a Check.
- Chatsanity: Add Checks for talking to NPCs.
- Cutscenesanity: Add Checks for the game's various cutscenes and similar scenes.
- The Pit: Toggle Checks for completing floors in The Pit.
